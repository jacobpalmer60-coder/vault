# League tools — progressive detail
Team Analyzer opens with team outlook, key stats, weaknesses and potential partners. Extra roster stats and coverage stay accessible. Discover can open for any viewed team using an explicit subject parameter without changing saved team identity. Manager history defaults to manager, trading style, volume and net value today; expanded columns retain the earlier price and fit detail, and position-specific price history is expandable. Player Rankings keeps player, age (desktop), listed price, market price and production; additional trend/VORP and small-screen stats are available by expanding columns, with horizontal scrolling for dense tables. All metrics, sorts and filters remain. Descriptive evidence is not an acceptance forecast. Test functional and mobile flows; novice user testing remains outstanding.
