# Prospective price validation
Capture current KTC and Vault premiums for all six formats daily, with actual UTC source timestamps and Git commit. Reject inputs older than 48 hours. Store compressed dated price-only snapshots on a dedicated GitHub release; never overwrite an existing date. This adds zero Sleeper calls. No personal data, league IDs or manager histories in snapshots.
Weekly evaluate a rolling 28-day window, excluding the last two days for ingestion lag. Compare fixed 25 player/pick pairs on matching completed trade packages using only a snapshot published before the trade UTC day. Reject modified assets and captures more than three days old. Price missing or ambiguous identities excluded; picks use same-year mid-round price only. Report missing snapshot and price coverage across formats, paired comparison to raw and full, and league-key clustered approximate intervals. No live model changes, weight selection or claim of acceptance. Release timestamps are provenance, not cryptographic immutability; authorized release administrators could delete assets. Do not backfill old captures. Initial reports may have few or zero eligible days. The pipeline starts accumulating genuine forward evidence on first successful capture.
