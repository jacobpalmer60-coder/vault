# Simple-first usability roadmap
Default experience: answer what should I do, explain why, then let the user inspect the evidence. Phase 1: existing Today dashboard becomes a team direction and next-step landing page, with find/check trade and roster review links, and a native disclosure for detailed odds, market movement and needs. No new valuation engine. Show unknown lineup data rather than fake ranks. Keep league context; isolate visit history per roster. Onboarding prioritizes username, with optional league ID, visible busy state, current-request guards and accessible error message. Keep standalone calculator. Phase 2: simplify trade results and advanced price explanations, page navigation and glossary; phase 3: test first-time tasks on desktop/mobile with actual new dynasty users. Automated structural and browser checks cannot establish novice usability. All existing tools remain accessible.
