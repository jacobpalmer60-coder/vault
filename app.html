Legend

Overall — Players + Picks combined, a team's real total dynasty value
Position Split — Share of player value by QB/RB/WR/TE
Players — Sum of rostered player values
Picks — R1-4 live from Sleeper
Opt PPG — Best lineup, league scoring
Longevity — Of the next 5 projected years (position-decay + arriving picks), how many still clear the real playoff line. Not age or pick count — a young, pick-poor roster that's already elite can out-project a pick-rich one that hasn't hit yet.
Archetype — Build type, from how you stand now vs. how long that lasts (see guide below)
Career — All-time W-L-T for this manager, summed across every season Sleeper's league-history chain has for this league
Proj. Record / Playoff % / Title % — Monte Carlo'd against the real remaining schedule using each team's Opt PPG as weekly strength (±22% week-to-week variance) — a rough estimate, not a guarantee

Archetype Guide

Every archetype comes from two independent standings — Contending (current player value + production: how strong you are right now) and Longevity (Vault.contentionWindow's 5-year projection: how many years that lasts) — each ranked Top 2 / Top Half / Bottom Half / Bottom 2 of the league. Draft capital (Picks) is tracked separately — shown as its own qualifier next to each pill — since a team's picks and its projected window don't always point the same direction.
